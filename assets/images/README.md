# Assets Directory

This directory contains project assets including logos, cover images, and other visual materials.

## Files

- `cover-image.png` / `cover-image.jpg` - Main cover image for social media and project branding
- `logo.png` / `logo.svg` - Project logo (if applicable)

## Usage

These images can be referenced in:
- README.md
- GitHub repository (social preview)
- LinkedIn posts
- Other documentation

## Recommended Formats

- **Cover Image**: PNG or JPG, 1200x630px (LinkedIn), or 1280x640px (GitHub social preview)
- **Logo**: SVG (scalable) or PNG with transparent background
